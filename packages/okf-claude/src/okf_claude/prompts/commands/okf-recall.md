Find what OKF memory knows about: $ARGUMENTS

1. `mcp__okf__search` with the topic in plain words. If search is unavailable,
   browse with `mcp__okf__read_index` (start at the root, go deeper where the
   descriptions match) and `mcp__okf__list`.
2. Open the most relevant concepts with `mcp__okf__get` (and recent matching
   ones under `episodes/`), following links when they look relevant.
3. Answer from what you read, citing each concept id you used. Say plainly
   what memory does not cover; do not fill gaps with guesses.

Do not write to memory in this command.
