Find what OKF memory knows about: $ARGUMENTS

Use the OKF MCP tools named in this session's "OKF memory" context: `mcp__okf__*`
for a single workspace, or `mcp__okf-<workspace>__*` when several are
configured. With several, query each workspace whose overview could cover the
topic.

1. `search` with the topic in plain words. If search is unavailable, browse
   with `read_index` (start at the root, go deeper where the descriptions
   match) and `list`.
2. Open the most relevant concepts with `get` (and recent matching ones under
   `episodes/`), following links when they look relevant.
3. Answer from what you read, citing each concept id you used (and its
   workspace, when there are several). Say plainly what memory does not cover;
   do not fill gaps with guesses.

Do not write to memory in this command.
